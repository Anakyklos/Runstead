# Provider Abstraction Research — Issue #16 Standalone Experiment

> **Gate**: #16 authorizes research-only, disposable, standalone prototypes.  
> **This document is a research artifact** — no changes to `runstead run`, governor/executor/provider production boundaries.

---

## Research Question

Can we define a **minimal, portable provider interface** that:
1. Decouples Runstead core from OmniRoute-specific concepts (`RouteSafety`, `GatewayContractHealth`, `AttemptReceipts`)
2. Supports both OmniRoute and future first-party providers (ChatGPT Web direct, z.ai, Qwen Studio)
3. Preserves observable delivery state, attempt accounting, fail-closed model selection, distinct local/upstream request identities

---

## Proposed Interface (Draft)

```go
// ProviderClient is the minimal provider boundary.
// Excludes: RouteSafety, GatewayContractHealth, AttemptReceipts, DeliveryState
type ProviderClient interface {
    Complete(ctx context.Context, req ProviderRequest) (ProviderResponse, error)
    HealthCheck(ctx context.Context) (HealthResult, error)
    Models(ctx context.Context) ([]ModelInfo, error)
    Name() string
}

type ProviderRequest struct {
    ClientRequestID string   // Local deduplication identity (generated by governor)
    Model           string   // Model identifier
    Messages        []Message
    Stream          bool
}

type ProviderResponse struct {
    Content  string
    Metadata ProviderResponseMetadata
}

type ProviderResponseMetadata struct {
    StatusCode int
    RequestID  string        // UPSTREAM provider request identifier (transport evidence)
    SessionID  string
    Duration   time.Duration
    RetryAfter time.Duration
    ResetAt    time.Time
    Endpoint   string
    Model      string
    // NO DeliveryState — that's transport evidence, not derivable from success
}

type HealthResult struct {
    Healthy   bool
    Reason    string
    RateLimit *RateLimitInfo
    ModelInfo *ModelInfo
}
```

---

## Key Design Decisions (from reviewer feedback)

| Issue | Decision |
|-------|----------|
| **DeliveryState not derivable** | `ProviderResponseMetadata` has NO `DeliveryState`. Transport evidence (`sent_unconfirmed`, `response_started`, `completed`) is NOT `err == nil` or HTTP 200. |
| **Request identities distinct** | `ClientRequestID` = local deduplication (governor-generated). `RequestID` = upstream transport evidence (provider-returned). Never conflate. |
| **RouteSafety not declarative** | Adapter cannot assert `single attempt, no amplification` without observable send accounting. Must be measured conservatively. |
| **HealthCheck fail-closed** | Must NOT perform model-effect sends/retries/fan-out. Explicitly prohibited. |
| **Model selection fail-closed** | No empty-model → `"default"` fallback. Ambiguous model = refusal. |
| **Generalization deferred** | Per roadmap: additional providers only after two required paths demonstrate real substitution. |

## Experiment Plan (Standalone, Outside Production)

### Phase A: Interface Validation (No Runtime Changes)

1. **Type-check only** — `internal/provider/client.go` as standalone package
2. **Fake implementation** — `ProviderClient` with `Complete`, `HealthCheck`, `Models`, `Name`
3. **Adapter stub** — `ProviderClient → LegacyClient` conversion logic (not wired)
4. **Compile verification** — `go build ./internal/provider/...` only

### Phase B: ChatGPT Web Direct Sidecar Prototype (Python)

Location: `experiments/provider-abstraction/chatgptweb-sidecar/`

```
chatgptweb-sidecar/
├── pyproject.toml
├── chatgptweb/
│   ├── __init__.py
│   ├── client.py          # ProviderClient impl
│   ├── transport.py       # nodriver + SSE reconciler
│   ├── auth.py            # cookie persistence (encrypted)
│   ├── sentinel.py        # Sentinel handshake (PoW + Turnstile)
│   ├── drift.py           # sentinel/sdk.js hash probe
│   └── health.py          # HealthCheck (no model effects)
├── tests/
│   ├── test_client.py
│   ├── test_sse_reconciler.py
│   └── test_drift.py
└── README.md
```

**Key technical choices (per skill research):**
- **nodriver** (Python) — 0/31 Cloudflare blocked, direct CDP, no WebDriver artifacts
- **Session warming** — browser auth once, reuse `cf_clearance` + `oai-device-id` + access token until 401/403
- **SSE reconciler** — cumulative deltas + echo suppression (track last content hash)
- **Drift detection** — hash `sentinel/sdk.js` on startup + periodic
- **JSON-RPC over stdio** — decoupled from Go core

### Phase C: Substitution Evidence

Run **same protocol corpus** through:

2. ChatGPT Web sidecar (this prototype)

Measure:
